Service 1: API Calls (Weather): http://127.0.0.1:7871/
Purpose: Service 1 allows users to request real-time weather information for a city using an external API backend.

This project implements a chat-based assistant using Gradio ChatInterface. The assistant has a light Gen-Z style personality (short, friendly, emoji-friendly) while staying clear and usable.

The chat interface maintains conversation memory via Gradio’s history object, allowing the assistant to reference prior user messages and keep the interaction coherent across turns.

# Capstone: build a course-question assistant

Open [index.html](index.html) in a browser and keep it beside the Codex or Claude Code window. Its 15 sections reflow at half-screen width and link to the corresponding course PDFs in `01_materials/slides`. Slides 9–14 explain each Compound Engineering step while it runs. Use [instructor_runbook.md](instructor_runbook.md) for the minute-by-minute facilitation plan and [demo_brief.md](demo_brief.md) as the opening prompt for the live build.

The assistant is built from scratch during the live session in `05_src/course_question_assistant`. Start with this branch, which contains the teaching materials and build brief but no assistant implementation. Have the app dependencies and API key ready before class.

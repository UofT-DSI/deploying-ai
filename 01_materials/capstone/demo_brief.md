# Live build brief

Build a small Gradio chat app in `05_src/course_question_assistant` that answers questions about the Deploying AI course. Use the Markdown lessons in `03_instructional_team/markdown_slides` as the only knowledge source. Retrieve relevant slide sections, show the source file and slide heading in answers, and say when the slides do not support an answer. Follow the existing Gradio patterns in `05_src/simple_chat` or `05_src/course_chat`. Use dependencies already declared in `pyproject.toml`. Keep it small enough to explain in a 45-minute capstone.

The instructor can paste this brief into `/ce-brainstorm`, then use its result for `/ce-plan` and `/ce-work`. The brief states the desired app, not an implementation recipe; let each step expose its own decisions.
